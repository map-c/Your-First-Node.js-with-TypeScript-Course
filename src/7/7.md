# 使用 Hono 做 Web 开发

Node.js 生态中有 Express、Koa、Fastify、NestJS 等 Web 框架。Hono 的特点是 API 简洁、原生支持 TypeScript，并且以 Web 标准中的 `Request` 和 `Response` 为基础。除了 Node.js，它还可以运行在 Deno、Bun 和边缘运行时中。

本章以一个任务 API 为主线，完成从启动服务到发布后观测的完整过程：

1. 使用 Hono 和 Node.js 适配器启动 TypeScript Web 服务。
2. 使用 oRPC 和 Zod 定义带类型校验的 API。
3. 生成 OpenAPI 文档，并通过 Scalar 提供交互式 API 页面。
4. 了解 Cella 如何在 Hono 之上组织完整的全栈应用。
5. 使用 Apitally 采集请求、错误和性能数据。

## 环境准备

Hono、oRPC 和 Apitally 示例继续使用本课程的 Node.js 20 基线：

```bash
node --version
npm --version
```

示例已使用 Node.js 20、Hono 4 和 oRPC 1.14 验证。Cella 是独立的进阶案例，其当前版本要求 Node.js 24、pnpm、Docker 和 PostgreSQL。学习 Cella 时应使用单独的运行时和项目目录，不要直接修改前面示例的 Node.js 版本。

完成本章后，你应该能够解释 Hono 应用、Node.js 适配器、类型安全 API、OpenAPI 文档和监控中间件之间的关系，并能够独立搭建一个小型 Web API。
